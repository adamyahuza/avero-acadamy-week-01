Week 1 Reflection

My Experience

My first week at Averon Academy has been an important step in my web development journey.

I have started becoming more familiar with the learning environment, GitHub repositories, Markdown files, and the importance of organizing my work as a developer.

Creating my Week 1 repository has also helped me understand how developers use GitHub to store, organize, and share their projects.

What I Learned

During this week, I learned more about:

- Creating and organizing a GitHub repository.
- Using Markdown files.
- Understanding the purpose of a README file.
- Writing about my background and developer goals.
- Reflecting on my learning progress.
- The importance of keeping development work organized.

I also gained a better understanding of how GitHub can become part of my professional developer portfolio.

Challenges

One of my challenges is that I am still developing my confidence with some technical concepts and developer tools.

Sometimes I need more time to understand new commands, code, or technical instructions. However, I see these challenges as part of the learning process.

How I Will Improve

I will improve by practicing regularly, asking questions whenever I do not understand something, reviewing previous lessons, and building small projects.

I will also use GitHub more frequently so that I can become comfortable with repositories, files, commits, and version control.

Final Reflection

Week 1 has reminded me that becoming a developer is a continuous learning process. I am excited to continue with the Averon Academy program and improve my technical skills step by step.

I look forward to learning more about HTML, CSS, JavaScript, frameworks, APIs, GitHub, and deployment in the coming weeks.

My commitment: Learn, practice, build, and keep improving.
